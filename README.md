# Irish-Trad-Session-Archive
Weekly archive of [Erich Marschner's Baltimore Irish session list](https://tinyurl.com/irishtradsessions). Code can be found on [GitHub](https://github.com/BobbyCobby/Irish-Trad-Session-Archive); PRs welcome. The main thing running is [.github/workflows/archive.yml](.github/workflows/archive.yml), every Tuesday morning.

Access the archive here: [archive/README.md](archive/README.md).
